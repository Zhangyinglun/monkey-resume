# Domain documentation

Read `CONTEXT.md` before changing domain terms or evidence/review behavior.
Read the relevant decisions in `docs/adr/` before changing physical QA or the
model-led draft and publication lifecycle. This repository has one domain context.

Use the vocabulary in `CONTEXT.md` for domain concepts in issues, tests and
proposals. If a change contradicts an existing decision, identify the conflict
and update the decision as part of the authorized change.
