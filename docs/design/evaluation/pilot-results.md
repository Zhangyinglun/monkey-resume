# 合成内容审阅小试结果

## 结论

两个独立审阅上下文都识别了构造样例中的七组关键问题，并在两个相对
正确的对照草稿上给出内容通过，没有把合理压缩当作必须写全所有事实。
这个结果支持继续开发审查提示；不证明完整新生成流程更好，也不证明
真实简历或其他模型上的零错误。

## 方法

- 四个完全合成的草稿，共用一份虚构候选人证据和原始 JD。
- 审阅 A 会话：`ses_ec7327540ffezkjvO4Ffme1tNs`；审阅 B 会话：
  `ses_ec7325d3dffe1NlCjgrEmK2NUh`。
- 先只读 JD/正文，保存并冻结盲读 JSON；随后同一审阅上下文获取完整证据
  和作者取舍。两位审阅者看不到彼此输出或主线程期待标签。
- 本小试使用宿主默认调度；没有选择特定模型变体，报告不声称跨模型验证。
  模型实际版本/采样设置未在本记录中取得，不用于模型能力排名。
- 盲读和输入文件 SHA-256 保存在 `input-fingerprints.json`；结果文件
  见 `reviewer-a-content.json` 和 `reviewer-b-content.json`。
- 没有调用文档渲染、factual audit 或发布。所有结果如实报告
  `format_status=unavailable`、`publication_ready=false`。

## 观察

| 草稿 | 构造的情形 | 现有五项浅层检查 | 审阅 A | 审阅 B |
| --- | --- | --- | --- | --- |
| draft-a | 较完整、有来源的正文 | 长度 WARN，其余 PASS | 内容 pass；无阻塞 | 内容 pass；无阻塞 |
| draft-b | 旧姓名、遗漏重要冷却与领导贡献 | 全部 PASS | revise；2 组阻塞 | revise；2 组阻塞 |
| draft-c | 借用指标、扩大 scope/ownership、添加已否认能力 | 全部 PASS | revise；5 组阻塞 | revise；5 组阻塞 |
| draft-d | 保留主要 infra 能力、合理简写次要内容 | 长度 WARN，其余 PASS | 内容 pass；无阻塞 | 内容 pass；无阻塞 |

这里的浅层检查仅指 `check_content_quality.run_all_checks()` 的词数、
动词开头、重复、密度和语言模式五项，不是当前系统全部门禁。
不得将表格表述为旧系统会接受所有错误草稿。

七组关键问题是：旧姓名未更新；冷却遥测/诊断/技术领导整体遗漏；
添加已否认的 Terraform/Helm/Kafka broker 管理；认证 SLA 借给队列；
诊断提速写成完整恢复提速；队列指标及自主修复权限借给冷却项目；
同事的模型微调归到候选人。

两位审阅者均区分重要遗漏和合理取舍。draft-b 的“无关 AI/product”
理由被否定，不意味着内部助手和每条工程实践都必须展示；draft-d 在
保留主要能力后省略这些内容被接受。实际页数仍未知。

## 用词精度与误报边界

盲读阶段，两位均建议说明 `supported-scope incidents` 的范围；完整
证据没有更细类别，审阅 A 明确不把这个问题升级为事实错误。
二者也把 draft-d 的 `resolved` 对比来源 `mitigated` 记为精度建议，
因为上下文保留了自动缓解、范围与时间限制。后续作者应选更精确的用词，
但这一观察不建立“resolved 永远只是建议”的通用规则。

审阅 A 对 draft-b 的系统用途给出额外建议，审阅 B 没有相同的 Phase B
建议；关键 verdict 一致不代表所有措辞意见一致。保留原始结果，不把
两个审阅结果改造成完全相同的报告。

## 记录检查

主线程已执行 `python3 -B` 检查：

- 输入及盲读哈希未改变，所有 JSON 可解析。
- blocking finding 的路径可解析，引文确实出现在对应字段/数组中。
- source claim IDs 都存在，发现有理由和针对性修正。
- 四份 verdict 与主线程针对构造样例的期望一致。
- 所有八份内容评估都诚实标记格式不可用和不可发布。

这些检查只验证小试记录和已知期望，不证明模型的理由普遍正确。
没有独立人工专家标签、保留集、端到端对照、实际页面、反序成对比较或
跨模型验证。不得报告“100% 简历质量”或已获得统计可靠性。

## 下一阶段评估

实现完成后，同资料/同 JD 对比当前基线与新流程，加入未用于提示调整的
案例及更隐蔽的错误。分别测量生成质量和裁判漏报/误报，记录人工复核
意见。实际生成一页与可读性必须通过真实同源渲染验证。
重复或跨模型评估由观察到的分歧及实际使用范围决定，不照搬通用固定次数。
