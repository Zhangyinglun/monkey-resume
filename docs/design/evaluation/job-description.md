# Original JD — Cloud Infrastructure Engineer

Northlake Systems is hiring a Cloud Infrastructure Engineer to build and operate
reliable distributed services. The engineer will develop service and message
queue infrastructure, automate recurring production incidents, use telemetry
and logs to diagnose failures, and deploy containerized workloads on Kubernetes.

Required capabilities:

- Hands-on development in at least one of C#, Python, or Go.
- Distributed service reliability and production incident investigation.
- Practical Kubernetes deployment and operational automation.
- Ability to explain technical trade-offs and work with other engineers.

Helpful experience:

- Designing telemetry pipelines, actionable alerts, and diagnostic workflows.
- Technical team leadership and delivery of internal engineering tools.
- Kafka broker administration, Helm, and infrastructure as code.

The application requests an English one-page resume. No work authorization,
location, or legal-name requirement is specified.
